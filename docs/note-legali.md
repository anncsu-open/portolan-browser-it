# Note legali

Portolan Browser Italia è gestito dall'organizzazione GitHub
[anncsu-open](https://github.com/anncsu-open).

**Non è un sito istituzionale.** Non è gestito da una pubblica
amministrazione e non ne rappresenta nessuna. La veste grafica segue le
[linee guida di Designers Italia](https://designers.italia.it/) per i servizi
digitali della pubblica amministrazione, che sono pubbliche e riusabili. I
loghi degli enti nella pagina di partenza vengono dal registro Portolan e
indicano chi pubblica ciascun catalogo.

Il software è basato sul [Portolan Browser](https://github.com/portolan-sdi/portolan-browser)
ufficiale, nella versione indicata nel footer, con tema e configurazione
propri. I dati appartengono ai
rispettivi titolari e sono distribuiti con le licenze dichiarate in ciascun
catalogo.

Il sito è offerto così com'è, senza garanzie sulla disponibilità o sulla
correttezza dei dati mostrati.
